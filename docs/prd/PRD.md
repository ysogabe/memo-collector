## 1. 一文で

**今見ている画面に、声でひと言メモを貼る macOS アプリ。** ホットキーを押して話して離すだけで、スクショ・アプリ名・ウインドウ・URL・自分の一言を 1 件の記録として手元に残し、あとで Hermes や Claude Code が読める形で渡す。

## 2. 背景と課題

- 作業中に「これ後で調べたい」「ここ直したい」と思った瞬間はすぐ流れる。タスク管理アプリに書こうとすると、プロジェクト・タグ・期限・優先度の入力が摩擦になって書かない（Super Productivity で実際に挫折した）。
- テキストで書き残しても、**何を見ていて思ったのか**という文脈が抜ける。「この issue」「ここの null」「今の API 移行の話」は、画面がないと後から意味が通らない。
- 一方で、調査や実装そのものは AI エージェント（Hermes / Claude Code）に任せられるようになった。足りないのは**人間が見ていた文脈と、その瞬間の考えをエージェントに渡す入口**。

## 3. ターゲット

| ペルソナ | 状況 | 欲しいもの |
|---|---|---|
| **主: AI エージェントと働く開発者**（本人） | ブラウザ・VS Code・ターミナル・会議を行き来しながら、Claude Code や自作エージェントに作業を振っている | 思いついた瞬間に 3 秒で投げ込み、後でまとめてエージェントに渡せること |
| 副: リサーチ・企画職 | 論文・記事・資料を大量に読む。会議中にもメモしたい | 画面ごと残して後から「あの図どこだっけ」で探せること |

前提環境: Apple Silicon Mac（M1 以降）、macOS 15 以降、メモリ 16GB 以上推奨。

## 4. 設計原則

元会話で決まったものを優先順に並べる。機能判断で迷ったらここに戻る。

1. **入力の摩擦を最小にする。** 押す → 話す → 離す で終わる。入力時に分類・期限・優先度を求めない。
2. **キャプチャ時は重い処理をしない。** 保存までに走らせるのは STT だけ。解釈（意図・OCR・検索用ベクトル）は保存後に回す。
3. **コンテキストは Best Effort。** スクショ・アプリ・ウインドウは必須、URL などは取れたら付ける。何かの取得に失敗しても記録は必ず残す。
4. **タスク管理はしない。** 判断と実行はエージェント側。このアプリは記録をきれいに溜めて渡す入口に徹する。
5. **全部ローカル。** 音声・スクショ・テキストを外に出すのは、ユーザーが明示的に渡したときだけ。
6. **機能追加は、毎日使って不便だと確かめてから。**

## 5. スコープ

### 5.1 MVP（P0）

| ID | 機能 | 受け入れ条件 |
|---|---|---|
| F-01 | メニューバー常駐 | Dock に出ない。メニューバーにアイコンと未処理件数を表示 |
| F-02 | グローバルホットキーの Push-to-Talk | 既定 `⌥Space` 長押し。押している間だけ録音。キー変更可。0.3 秒未満の押下は誤操作として破棄 |
| F-03 | 前面ウインドウのスクショ | 押下時点のフォーカス中ウインドウ 1 枚を ScreenCaptureKit で撮影、WebP 保存。取得失敗時は画面全体にフォールバックし、それも失敗したらスクショなしで保存 |
| F-04 | コンテキスト取得 | アプリ名・バンドル ID・ウインドウタイトルは必須。URL は Safari / Chrome / Arc / Edge で取得（失敗時は空） |
| F-05 | 日本語 STT | ローカル実行。解放から保存可能まで p90 ≤ 2 秒（PoC: STT 単体 1.1 秒、意図推定と索引まで含めて 1.64 秒）。カスタム語彙（固有名詞辞書）を設定可能 |
| F-06 | 録音中 HUD と保存トースト | 押下中は小さな HUD に波形と「話してください」。保存後 1.5 秒トースト「保存しました」と文字起こしを表示。トーストから 5 秒以内は取り消し可能 |
| F-07 | Context Inbox | メニューバーから開く一覧。新しい順。各行にアプリアイコン・時刻・注釈先頭・意図ラベル |
| F-08 | 詳細ビュー | スクショ・メタデータ・注釈を表示。注釈の手直し、削除、「Markdown でコピー」 |
| F-09 | 意図ラベル（自動・非同期） | 保存後に `todo / research / code / note / schedule` と「日時の言及あり」を付ける。確信度 0.7 未満は「未分類」。ユーザーが変更できる |
| F-10 | 秘密情報ガード（非同期） | 保存後にスクショを OCR し、API キー・トークン・パスワード表示を検出したら「要確認」マーク。マークが付いたものは外部へ渡す前に必ず確認を挟む |
| F-11 | 検索 | Inbox 上部の検索欄。日本語の自然文で注釈・タイトル・URL・**スクショの見た目**を横断検索 |
| F-12 | ローカル MCP サーバー | Hermes / Claude Code から読めるツールを公開（§9） |
| F-13 | 除外設定 | 指定アプリ（例: 1Password、銀行アプリ）が前面のときはスクショを撮らない |

### 5.2 次の版（P1）

- Meeting mode: Zoom / Teams / Meet を検出したら HUD に「会議中」表示。会議側のマイクがミュートでないときに警告（取得できる範囲で）
- アプリ別の追加コンテキスト: VS Code のファイルパスと行、Finder の選択ファイル、Terminal の cwd
- 「Hermes へ送る」「Claude Code へ送る」ボタン（MCP 経由ではなく能動送信）
- 重複のまとめ表示（同じ画面への連続キャプチャ）
- STT を FluidAudio（Core ML / ANE）に切替できるようにする

### 5.3 将来（P2）

- 会議アプリの出力音声（前後 30 秒）を Core Audio Process Tap で添付。**参加者の同意と組織のポリシーを確認する UI を前提**とする
- Apple Reminders / Calendar への書き出し
- 英語 UI（英語なら d1-omni-600M による軽量化を再検討）

### 5.4 やらないこと（Non-goals）

- **タスク管理**: プロジェクト・タグ・優先度・サブタスク・繰り返し・時間計測・ガントは持たない
- **入力時の分類要求**: 期限やプロジェクトを聞き返さない
- **キャプチャ時の OCR / VLM**: 保存までの経路に重い解析を入れない
- **ウェイクワード・常時聞き取り**: Push-to-Talk のみ
- **会議音声の録音（MVP）**: 自分の声の注釈だけを扱う
- **クラウド同期・アカウント**: MVP では作らない

## 6. ユーザー体験

### 6.1 キャプチャ

```
⌥Space を押す
  ├ 押した瞬間のウインドウを撮る（シャッター音なし、枠が一瞬光る）
  └ HUD「● 話してください」＋ 波形
話す 「このissueの修正、Claude Codeにやらせて。ストリーミング対応のところ」
⌥Space を離す
  └ 約 1.5 秒後にトースト
      ┌──────────────────────────────────┐
      │ ✓ 保存しました  GitHub · Issue #128   │
      │ 「このissueの修正、Claude Codeに…」    │
      │                         取り消す    │
      └──────────────────────────────────┘
  └ 数秒後（裏で）意図ラベル「code」、検索インデックス、秘密情報チェック
```

### 6.2 Inbox

```
┌ Context Inbox ─────────────────── 🔍 ビデオ会議の画面 ┐
│ 今日                                                 │
│  23:16  GitHub     Hermesのアダプタに使えそう   research │
│  22:48  VS Code    ここのnullの理由を直して      code     │
│  21:32  Preview    PSOのところを明日までに読む   todo  📅 │
│  18:05  Terminal   ghの認証トークンが古い  ⚠要確認  todo   │
│ 昨日                                                  │
│  …                                                    │
└──────────────────────────────────────────────────────┘
```

詳細ビュー: スクショ（クリックで拡大）／アプリ・タイトル・URL／注釈（編集可）／意図ラベル／[Markdown でコピー] [削除]。「要確認」のときはスクショの検出箇所をハイライトし、[マスクして渡せる状態にする] を出す。

### 6.3 状態とメッセージ

| 状況 | 表示 |
|---|---|
| 画面収録の権限がない | 「スクショを撮るには画面収録の許可が必要です。[システム設定を開く]」。注釈とメタデータだけで保存は続ける |
| 無音・短すぎる録音 | 「声が入っていませんでした。もう一度 ⌥Space を押して話してください」。記録は作らない |
| STT 失敗 | 音声ファイルを残して保存し、「文字起こしに失敗しました。[再試行]」 |
| URL が取れない | 何も出さない（空欄で保存） |

## 7. データモデル

1 キャプチャ = 1 レコード + 添付ファイル。

```jsonc
// ContextRecord
{
  "id": "01JABCD...",                 // ULID
  "captured_at": "2026-10-08T23:15:32+09:00",
  "app": { "name": "Google Chrome", "bundle_id": "com.google.Chrome" },
  "window": { "title": "Support streaming events · Issue #128", "frame": [0, 38, 1440, 862] },
  "url": "https://github.com/opendots/opendots/issues/128",   // null 可
  "extra": {},                         // P1: file_path, line, cwd, selected_file …
  "screenshot": "captures/2026/10/08/231532.webp",           // null 可
  "audio": "captures/2026/10/08/231532.m4a",                 // 保持期間の設定に従い削除
  "annotation": { "text": "このissueの修正、Claude Codeにやらせて", "stt_engine": "whisper-large-v3-turbo", "edited": false },
  "triage": {                          // 非同期で埋まる。null 可
    "intent": "code", "intent_confidence": 0.84, "mentions_datetime": false,
    "model": "LiquidAI/d1-3B@051bcc4"
  },
  "guard": { "status": "clear" | "needs_review" | "masked", "findings": [ { "kind": "github_token", "bbox": [x, y, w, h] } ] },
  "handoff": [ { "to": "claude-code", "at": "…", "via": "mcp" } ],
  "status": "inbox" | "done" | "archived"
}
```

- 保存先: `~/Library/Application Support/ContextCapture/` に SQLite（メタデータ + ベクトル 256 次元）と `captures/` 配下のファイル。
- 音声は既定で 7 日後に削除（文字起こしは残す）。スクショの保持期間は設定可能。
- エクスポート: レコード 1 件を Markdown + 画像で書き出せる（エージェントへの貼り付け用）。

## 8. アーキテクチャ

```
                         ┌──────────── ContextCapture.app (Swift / SwiftUI, MenuBarExtra) ────────────┐
 ⌥Space ─ HotKey ───────▶│ CaptureCoordinator                                                        │
                         │   ├ ContextProviders: App / Window (AX) / URL (AppleScript) / Screenshot (SCK)│
                         │   ├ AudioRecorder (AVAudioEngine, 16kHz mono)                                │
                         │   └ STTProvider ── Whisper turbo (Metal) │ FluidAudio Parakeet JA (ANE)      │
                         │ RecordStore (SQLite + files)                                               │
                         │ TriageQueue (非同期・直列)                                                  │
                         │   ├ IntentClassifier ── d1-3B（テキストのみ、オンデマンドロード）              │
                         │   ├ SecretGuard ─────── Vision OCR + パターン（主）／d1-3B 補助                │
                         │   └ Indexer ─────────── EmbeddingGemma 2（注釈+スクショ融合、256 次元）        │
                         │ MCPServer (stdio / localhost)                                               │
                         └───────────────────────────────────────────────────────────────────────────┘
                                                  │
                                    Hermes ・ Claude Code ・ その他 MCP クライアント
```

### 8.1 モデル配置（PoC の結論）

| 処理 | 実行タイミング | モデル | PoC 実測 |
|---|---|---|---|
| 文字起こし | 同期（保存前） | Whisper large-v3-turbo（MLX）→ FluidAudio と比較して確定 | 1.1 秒 / CER 7.4% |
| 意図・日時言及 | 非同期 | **d1-3B**（注釈テキストのみ） | 0.3〜0.5 秒 / 未見データ 95.5% |
| 秘密情報 | 非同期・受け渡し前に必須 | **Apple Vision OCR + 正規表現** | 0.2 秒 / 4/4・誤検知 0 |
| 検索インデックス | 非同期 | **EmbeddingGemma 2**（融合 256 次元） | 0.8 秒 / R@3 0.93 |
| 画面種別 | 同期・軽量 | モデル不要（バンドル ID とタイトルのルール） | - |

- **d1-omni-600M は日本語では採用しない**（意図 54.5%、音声直接 16.7%）。
- **メモリ方針**: 常駐は STT と EmbeddingGemma のみ。d1-3B（MPS 6.3GB）は最初のトリアージで読み込み、10 分使われなければ解放。3 つ同時常駐は MPS 約 11GB で基準超過。
- **推論ランタイム**: PoC は Python（torch MPS）。製品では Swift から呼べる形が要る。候補は (a) 同梱の Python ヘルパープロセスを XPC で呼ぶ、(b) Core ML / MLX Swift へ変換。d1 は `trust_remote_code` の独自ヘッドを持つため (a) から始め、(b) を並行調査する。

### 8.2 権限

| 権限 | 用途 | 拒否されたとき |
|---|---|---|
| マイク | 注釈の録音 | アプリは使えない（オンボーディングで説明） |
| 画面収録 | ウインドウのスクショ | スクショなしで保存を続ける |
| アクセシビリティ | フォーカス中ウインドウ・タイトルの取得、グローバルホットキー | アプリ名だけ保存 |
| オートメーション（ブラウザごと） | URL 取得 | URL なしで保存 |

## 9. 外部連携（MCP）

元会話の方針どおり、ツールは 6 個に絞る。

| ツール | 内容 |
|---|---|
| `list_inbox(since?, intent?, limit?)` | 未処理の記録一覧（注釈・アプリ・URL・意図・要確認フラグ） |
| `search_captures(query, limit?)` | 自然文検索（§F-11 と同じ） |
| `get_capture(id, include_image?)` | 1 件の詳細。`include_image` はガード状態が `clear` か `masked` のときだけ画像を返す |
| `add_note(id, text)` | エージェント側からの追記（調査結果のリンクなど） |
| `mark_done(id)` / `archive(id)` | 状態の更新 |

- 既定は **読み取りと状態更新のみ**。記録の削除はエージェントに許さない。
- `needs_review` の画像は MCP から返さない。ユーザーが Inbox で確認して `masked` か `clear` にしたものだけ渡す。

## 10. 非機能要件

| 項目 | 目標 |
|---|---|
| 解放 → 保存トースト | p90 ≤ 2.0 秒（M1 / 16GB で計測） |
| 押下 → 録音開始 | ≤ 150ms（頭の言葉を落とさない） |
| アイドル時 CPU | ≤ 1%（録音もトリアージもしていないとき） |
| 常駐メモリ | アイドル ≤ 4GB、トリアージ中 ≤ 10GB（16GB 機で他アプリと共存） |
| 記録の信頼性 | どの取得が失敗しても、録音できていれば記録は残る |
| ネットワーク | 初回のモデル取得以外は通信しない。モデル取得はオンボーディングで明示 |
| データ | 保存先は FileVault の範囲。エクスポート・削除はいつでも可能 |

## 12. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 会議中にミュート解除のまま話してしまう | 相手に聞こえる | P1 の Meeting mode でミュート状態を警告。それまではオンボーディングで注意喚起 |
| 秘密情報がエージェントに渡る | 漏洩 | 受け渡し前のガード必須化、除外アプリ設定、`needs_review` の画像は MCP で返さない |
| 実発話で STT・意図精度が落ちる | 手直しが増えて使わなくなる | カスタム語彙、意図は確信度で未分類に逃がす、実発話 100 件で再評価 |
| d1-3B のメモリ | 16GB 機で重い | オンデマンドロード、量子化版の検証、だめなら意図付けを Hermes 側 LLM に移す |
| `trust_remote_code` | 供給網リスク | revision 固定、更新時にコード差分をレビュー |
| モデルのライセンス | 配布可否 | d1 は LFM Open License v1.0、EmbeddingGemma 2 は表記を要確認。**同梱せず初回にダウンロード**する方式を基本に、配布前に法務確認 |
